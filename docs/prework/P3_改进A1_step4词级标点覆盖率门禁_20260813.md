## 1. 判定契约（三档，与人工评审语义对齐）

| 档 | 触发 | 实例（b2 实录） |
|---|---|---|
| **hard_fail** | 语义 token 不一致（CJK 字/字母数字串/比较与数学符 ≤≥<>＜＞=±×∑ 与 %‰℃° 等单位记号）；真值行落空（覆盖率硬校验）；空转写 | #01 滑坡**地段**→滑坡**地质**（D1）；#08『14≤B<18』整条漏渲（D2）；＞550→≥550 同级 |
| **warn** | 仅标点 token 差异（，。、；：等全半角常用标点替换/增漏）；转写多余行（装饰性文字） | #08-r2『，』→『；』（人工终审「带瑕疵接受」的同级物） |
| **pass** | 逐词逐标点全对（空白差异忽略） | — |

匹配口径（文档化决策）：**匹配单元=行**——真值 `expected_texts` 条目可含内嵌换行（一个可见元素跨多物理行，r2242 实况形态），先拆行再配对（保留行→元素归属），覆盖率分母=拆行后行数；**五段式配对**：① 精确（语义+标点 token 全等，行序无关；**重复行标签可去标签匹配**——A2 #07 口径：同元素内「LABEL | CONTENT」的重复 LABEL 渲染为合并单元格＝语义等价重组＝pass）→ ② **reflow 修复**（A2 口径「纯换行 reflow＝软分隔＝pass」：真值行 ↔ 相邻未配对转写行拼接（拆行向）或转写行 ↔ 相邻未配对真值行拼接（并行向，窗口 ≤4 行），语义 token 全等即配对、仅标点差记 warn）→ ②′ **元素级 token 流对账**（跨换行点重排+内部缺陷共存的卡，A2 #01-r1 形态：元素未配对行拼接 ↔ 相邻转写行窗口按相似度选窗 ≥0.6，语义 token 流 SequenceMatcher 逐段产出 semantic_diff（hard）、标点流相异另记 punct_diff（warn）——把「重排噪声」与「真缺陷」分离定位）→ ③ 相似度贪心配对（真实差异行，阈值 0.5，产出 semantic/punct findings）→ ④ 余量 line_missing/line_extra；**行内严格**（逐 token 比对）；未知字符归语义面（保守从严）。**归一化（A2 契约③）**：空白不敏感（#09 数字 kerning 先例）+ NFKC 全/半角等值形折叠（＜≡<、（）≡()、，≡, 宽度变体等同；折叠后的**符号替换**（，→；）仍相异照记 punct_diff）；**覆盖单射（A2 契约④）**：真值单元恰配一次，重复渲染的多余份记 line_extra warn。卡判定：任一 hard → hard_fail；否则有 warn → warn；否则 pass。报告级 overall 同规则聚合；CLI 退出码 0=pass/warn（warn 记录不拦截）、1=hard_fail 或缺件。

## 2. 输入与真值面

- 输入：step4 run 目录（`step4/requests-manifest.json` 的 card_index/source_card_id/presentation + `step4/images/`）+ 该 run 消费的发布 fixture。
- 真值：fixture 逐卡 `expected_texts`（其 model validator 保证与 `display_text_provenance` 逐条互证）——与评审人「对照 r2242 真值」实践同源；报告记 fixture 路径+sha256 供谱系。
- 出图命名解析：`step4-card-{index:02d}-{cardid前8位}[-rN].png`，**有重发件取最高轮次**（与 image_review_sheet 的 supersede 语义一致；-r2 由收口流程追加落盘、原图保留）。
- 转写绑定：`--transcripts-json` 条目按 `image_sha256`（强绑定，优先）或 `card_index` 键入；无绑定即拒（fail-closed）。
