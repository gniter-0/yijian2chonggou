## 1. 判定契约（三档，与人工评审语义对齐）

| 档 | 触发 | 实例（b2 实录） |
|---|---|---|
| **hard_fail** | 语义 token 不一致（CJK 字/字母数字串/比较与数学符 ≤≥<>＜＞=±×∑ 与 %‰℃° 等单位记号）；真值行落空（覆盖率硬校验）；空转写 | #01 滑坡**地段**→滑坡**地质**（D1）；#08『14≤B<18』整条漏渲（D2）；＞550→≥550 同级 |
| **warn** | 仅标点 token 差异（，。、；：等全半角常用标点替换/增漏）；转写多余行（装饰性文字） | #08-r2『，』→『；』（人工终审「带瑕疵接受」的同级物） |
| **pass** | 逐词逐标点全对（空白差异忽略） | — |

匹配口径（文档化决策）：**匹配单元=行**——真值 `expected_texts` 条目可含内嵌换行（一个可见元素跨多物理行，r2242 实况形态），先拆行再配对（保留行→元素归属），覆盖率分母=拆行后行数；**五段式配对**：① 精确（语义+标点 token 全等，行序无关；**重复行标签可去标签匹配**——A2 #07 口径：同元素内「LABEL | CONTENT」的重复 LABEL 渲染为合并单元格＝语义等价重组＝pass）→ ② **reflow 修复**（A2 口径「纯换行 reflow＝软分隔＝pass」：真值行 ↔ 相邻未配对转写行拼接（拆行向）或转写行 ↔ 相邻未配对真值行拼接（并行向，窗口 ≤4 行），语义 token 全等即配对、仅标点差记 warn）→ ②′ **元素级 token 流对账**（跨换行点重排+内部缺陷共存的卡，A2 #01-r1 形态：元素未配对行拼接 ↔ 相邻转写行窗口按相似度选窗 ≥0.6，语义 token 流 SequenceMatcher 逐段产出 semantic_diff（hard）、标点流相异另记 punct_diff（warn）——把「重排噪声」与「真缺陷」分离定位）→ ③ 相似度贪心配对（真实差异行，阈值 0.5，产出 semantic/punct findings）→ ④ 余量 line_missing/line_extra；**行内严格**（逐 token 比对）；未知字符归语义面（保守从严）。**归一化（A2 契约③）**：空白不敏感（#09 数字 kerning 先例）+ NFKC 全/半角等值形折叠（＜≡<、（）≡()、，≡, 宽度变体等同；折叠后的**符号替换**（，→；）仍相异照记 punct_diff）；**覆盖单射（A2 契约④）**：真值单元恰配一次，重复渲染的多余份记 line_extra warn。卡判定：任一 hard → hard_fail；否则有 warn → warn；否则 pass。报告级 overall 同规则聚合；CLI 退出码 0=pass/warn（warn 记录不拦截）、1=hard_fail 或缺件。

## 2. 输入与真值面

- 输入：step4 run 目录（`step4/requests-manifest.json` 的 card_index/source_card_id/presentation + `step4/images/`）+ 该 run 消费的发布 fixture。
- 真值：fixture 逐卡 `expected_texts`（其 model validator 保证与 `display_text_provenance` 逐条互证）——与评审人「对照 r2242 真值」实践同源；报告记 fixture 路径+sha256 供谱系。
- 出图命名解析：`step4-card-{index:02d}-{cardid前8位}[-rN].png`，**有重发件取最高轮次**（与 image_review_sheet 的 supersede 语义一致；-r2 由收口流程追加落盘、原图保留）。
- 转写绑定：`--transcripts-json` 条目按 `image_sha256`（强绑定，优先）或 `card_index` 键入；无绑定即拒（fail-closed）。

## 3.1 live 校准闭环（A2 双道校准 → 匹配器三修 → 真转写 18/18）

A2 双道校准（`P3_A2_step4词级门禁live校准_20260813.md`，d90afa9）以 18 卡金标为准绳：**两道 hard_fail 召回 2/2、零误放行**；全部分歧为误报向。按其 G1-G3 归因落三修（本件）：
- **R1 显式字形折叠表**：∑≡Σ、≦≡≤、≧≡≥（NFKC 无兼容分解的视觉同形对；只折字形不折语义，> vs ≥ 照旧 hard）——消 #14 live 误报；
- **布局分隔记号丢弃**：`|`/`/`（含全角）系真值的单元格边界标注与转写器的分隔替代（图面是网格线非字符），两侧一律不参与比对（内容斜杠 km/h 两侧对称丢弃仍等价）——消 #06 live 误报（G1/R4 的匹配器侧治本，转写 prompt 约定仍可叠加）；
- **元素级对账的去标签候选**：重复行标签的去标签形参与 ②′ 窗口选择（全形/去标签形取相似度更高者）——消 #07 真转写「标签独立成行+条目自由折行」形态误报（R3 剩余项）。
- 复放验证：**A2 真 vision 转写实录 fixture 复放 18/18 全对**（`test_a2_live_vision_transcripts_replay_matches_human_verdicts`，零网络、永久回归）——覆盖逐单元格转写、罗马数字字母化、∑ 归一、分隔替换、自由折行全部真实形态。`known_gate_divergence` 字段因分歧归零而不再需要。

## 3.2 R4/R5 收尾（A1.1 卡，零 live）

- **R4 转写行约定**：live 道 prompt 增补『表格卡整行转写为一行、单元格间以 " | " 连接、禁止一行拆多行』——从源头消解逐单元格碎行（G2 主因）；**prompt 版本随 `transcriber_id` 入报告**（`live:{model}:prompt-v2`，A2 提醒：转写实录缓存/复放按版本区分谱系）。纪律内零 live 验证：常量与 id 契约由 `tests/test_migration_run_step4_text_gate.py` 钉住（migration 模块按路径显式装载，同 relay_preflight 先例）；行为效果留待下一轮 live 校准实测（复放道零影响——fixture 按 image_sha256/card_index 键入，不携 transcriber_id）。
- **R5 机拦人裁分层输出**：报告版本 **`step4-text-gate-report/1.1`**——逐卡新增 `disposition` 字段按 verdict 定向：pass→`auto_accept`、warn→`auto_archive_with_note`（自动记档放行）、hard_fail→`human_adjudication`（**机器只拦截，处置权路由人工/重发道，非自动废图**；两道零漏报为该分层背书）；映射由 model validator 钉死（错标即拒，独立于自证哈希），CLI stdout 汇总附 `human_adjudication_cards` 清单。真语料双向 smoke 复跑不变：真值 16/16 pass（exit 0）、注入缺陷精确 2 hard+1 warn（exit 1，adjudication 清单=[1,8]）。
- R5 的金标集 `known_gate_divergence` 消费支持**不落**：双道分歧归零（§3.1）且有永久回归钉住，按 A2 原提案该字段仅在分歧存续期有意义（「A1 采纳 R1/R3 后逐条摘除」→ 已全部摘除）；若下一轮 prompt-v2 live 校准再现分歧，随其登记一并落消费分支。

## 5. 用法

```
# 零网络（人工/金标转写件）：
uv run python migration/run_step4_text_gate.py \
    --run-dir exams/gonglu_golden5_rehearsal/data/live_runs/20260812-rehearsal-b2-9lhvgu4b \
    --release-fixture scripts/tests/fixtures/v2/release_fixtures/gonglu_phase2r2242_step3_reviewed_release.yaml \
    --transcripts-json <转写件.json>
# live 视觉读图道（A2 卡校准后启用）：--allow-live [--env-file .env]
```

报告落 `<run-dir>/step4/text-gate-report.json`（`step4-text-gate-report/1.1`，common.hashing 自证哈希，逐卡 findings + `disposition` 机拦人裁定向 + 汇总三计数 + overall）。
