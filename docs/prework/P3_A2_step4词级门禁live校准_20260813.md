## 3. 调整建议（按性价比排序，供 A1 落 R 轨）

| # | 建议 | 消灭的误报 | 成本 |
|---|---|---|---|
| R1 | tokenizer 语义 token **等值字形折叠表**：＜→<、＞→>、≦→≤、≧→≥、∑→Σ、～→~、Ⅰ..Ⅻ→I..XII（折宽度/字形，**不折语义**：＞ vs ≥ 照旧 hard） | #14、#08-r2 离线、#08-r2 live 的字母化半数 | 极低（一张映射表） |
| R2 | reflow 拼接从『相邻未配对窗 ≤4』升级为**逐真值元素全序对齐**（未配对转写行按序全量拼接后与未配对真值元素做 token 流子序列匹配），或至少 span 放开到单真值元素的转写行数上限 | #11、#06、#08-r2 live 的行碎化 | 中 |
| R3 | 行首**重复标签容忍**：真值相邻行共享相同行首标签 token 段时，允许标签省略的转写按组匹配（配 warn 或 pass+note） | #07 双道 | 中 |
| R4 | live 转写 prompt 增加一句**行约定**：『表格卡整行转写为一行、单元格间以 " | " 连接』——把转写形态对齐真值行约定，从源头消解大半 G2（实测该模型对 verbatim 指令遵从性好） | #06/#08/#11 的大部分 | 极低（改 prompt 常量；注意 transcriber_id 应携 prompt 版本） |
| R5 | 生产姿势（R1-R4 落地前）：门禁 hard_fail ≠ 自动废图，**路由到人工/重发道**；两道零漏报支撑「机拦人裁」分层——warn 自动记档、hard_fail 人工确认，人工载荷 ≈27% 并随 R1/R2 递减 | — | 流程约定 |

金标集侧配套（已向 A1 提议）：增可选字段 `known_gate_divergence:{machine_verdict, reason}`——端到端回归断言改为「无该字段时 gate==expected_verdict，有时 gate==machine_verdict」，金标保留人工真值、分歧显式登记；A1 采纳 R1/R3 后逐条摘除。
