## 7. 风险与注意事项

- **>400 高危熔断**：见 §3 统计，触发时不要擅自提高上限，先给用户三选一（限额/抽样/加钱）。
- **双 census 格式**：消费端只认 `census.json`；v1 文件仅作交叉审计，不要删。
- **老仓只读**：任何脚本不得写 yijian2（含字节码：跑旧仓模块用 `dont_write_bytecode`）。
- **电脑卡顿**：多半来自多个并行 agent 会话 + OCR 跑批同机竞争；重开后第一遍收尾只剩 8 章（10-17，≈10-20 分钟机时），无需再开多路并行。
