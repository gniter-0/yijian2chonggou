### 归因结论（对照 D1/D2/D3）

逐卡对照 fixture 发现：**bundle 的 `GenericCardContract` 早已携带全部结构真值**——diagram 卡有 `diagram_node_ids` + `semantic_layout_edges`（源/靶节点+关系词）且节点标签可由 `visible_texts.semantic_node_id` 映射；table 卡有 `table_contracts.reviewed_grid` 完整单元格图（含表题行 r0）。而 v1 prompt（r119 源文本投影）只发 presentation + visible_texts 裸文本。**D1 三张 C 级 diagram 的病根是 prompt 信息不足（结构未入 prompt），非模型读不懂**；D2/D3 则缺字形/覆盖率硬性要求。归因=信息缺失为主、模型渲染能力为辅（见 #12 残余）。

### prompt v2 设计与驱动改动（默认 v1 逐字节不变）

1. 全卡追加三条硬性要求：①比较/区间符号逐字形保真（＞≠≥，样例点名 ＞550）；②每条 SOURCE 项完整渲染恰一次、表题行必须作为表上方标题行；③禁空框/禁臆造任何框、节点、行列、连线、文字。
