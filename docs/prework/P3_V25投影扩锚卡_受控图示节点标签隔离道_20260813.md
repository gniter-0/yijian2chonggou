## 3. 施工中的三处设计内收紧（A 签框架内的偏差声明）

1. **铸造改显式 opt-in（缺省关）**。A 签原文按「受控图示在场即铸」理解；实测 V25 现役 lane（r14 `build_live_sample_contexts` → 五章受控图页）在「在场即铸」下必然撞上自己的 V25 拒绝门——先例回放（test_phase2r142 系）当场变红。opt-in 让所有既有 lane 保持「空」、拒绝门恒不触发，b1e/未来启用卡显式开铸。与「变体载非空即拒」的核准原则同轴。
2. **版本字面量随载而变（铸了才 v6）**。A 签原文「新建投影一律 v6」；实测 v6-always 使冻结**人签**表续评审侧车（`step2a_request.py` L395 pin `review.projection_id == source_projection.projection_id`）在重建回放中全体失配——phase2r07/r0981 十用例变红，人签件不可重签。随载而变保住全部冻结 pin，同时保持「非空 ⇒ v6」的版本忠实性；未铸页 dump 与旧代码逐字节同（含版本字面量）。
3. **铸造加政策 INCLUDED 门**。规则表原文未列政策处置过滤；无此门则水印/噪声角色节点的 label 也会铸锚（fail-open 方向）。与一般铸造道的「政策先行」同轴，合成钉在案。
