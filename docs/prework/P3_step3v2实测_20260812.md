## 4. 与 v1 三卡整体回显证伪史对比

| 维度 | v1（三代表卡一次性整体回显） | v2（单卡一发，本场） |
|---|---|---|
| chatgpt2api-new | **空数组逃逸**：稳定回空 draft_cards，两轮响应字节级相同（含错 schema_version），补强 system 无效（strict 当提示不当约束） | 未走该通道（预检 P2a 判 strict 不强制，不满足 v2 前置） |
| 2chat 非流式 | **~125s Cloudflare 掐断**（502/524 HTML）——网关窗 < 三卡生成时长 | 不适用（v2 单卡 17-32s，远离窗口） |
| 2chat 流式 | 上游 APIError（v1 驱动 --stream 轮） | **6/6 echo_exact** |
| 输出规模 | ~4-6K tokens 一发（user_content 9,627 B） | 0.6-1.5K tokens/卡（输入 2.4-4.9KB/卡） |
| 已知失败模式防线 | 判负散在（result-schema 级） | 专用判负码内建：`empty-draft-cards-escape`、`result/card-version-echoed-input`（本场零触发） |

结论：v1 的唯一硬断点（超长受约束生成 × 网关窗口 × strict 不强制三重夹击）被 v2 的「颗粒降级 + strict 强制通道 + 流式」组合解除；step2b 同量级先例（5/5）外推成立。

## 5. 运维注记

1. 2chat 上游 502 瞬断真实存在（本场 8 次调用中 1 次，恰在探针位）：驱动探针先行 + fail-closed 生效，未烧业务卡费；重跑即愈。跑批前探针纪律保持。
2. 单卡时延与输入规模弱相关（2.4KB→17.3s，4.9KB→31.5s），外推每卡 ~15-35s；N 卡批量 ≈ N×25s + 探针。
3. 重发身份链路本场未触发（零失败卡）；离线回归已覆盖新身份生成规则（attempt+manual_reissue_reason 进 seed）。
