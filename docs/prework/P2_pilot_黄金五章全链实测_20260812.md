## 2. 当前中继（chatgpt2api-new @127.0.0.1:3100，ChatGPT 网页逆向）能力边界

**可用面**：小 payload（≲40KB）简单/中等 schema 的 strict chat（探针、step2b、V25 卡分组）；图像生成（gpt-image-2，1024x1536，b64_json，与 r119 结论一致）。
**不可用面**：
1. **>40~70KB 请求体一律 502**——`api/ai.py:133` 把上游调用异常包装为 502；限制在 ChatGPT 网页单条消息长度层，**加账号无效**（配额/并发与此无关；同账号小请求 100% 成功）。
2. **复杂嵌套 strict json_schema 不被强制**——step3 的 ResponseDocument（minItems=3 的 draft_cards）被稳定回以空数组，中继把 schema 当提示而非约束解码。
