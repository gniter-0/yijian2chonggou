## 2. 唯一分歧归因（#07-r1，附探针实证）

- **现象**：v2 转写把合并标签表格并成 1 行（v1 为 11 行），且**漏掉末行**
  『支架 | （6）支架不得与应急安全通道相连接。』→ 机判 hard_fail（semantic_diff + punct_diff）。
- **图面无辜**：该行图面确有——金标人工逐字、v1 实录、探针复测三方均含之；人工 expected=pass 判的是图。
- **探针复测**（同图同 prompt 温度 0，+$0.0117 入账）：漏行**未复现**（『支架 | （6）…』完整转出）
  → 漏行是 **vision 抖动**而非 prompt-v2 系统性缺陷；温度 0 下 vision 道仍非确定。
- **合并形态本身无误报**：探针转写（三条重复标签行并作一行 + 支架行独立）喂已提交门禁 → **pass、
  覆盖率 1.0、4/4 配对**——A1.1 的元素级对账+标签合并等价已完全吸收该形态。
- **定性**：机判 hard_fail 是门禁对其输入（缺行转写）的**正确拦截**；按 R5 分层该卡定向人工裁定，
  人工看图即放行。归因类别命名 **G4「vision 抖动性整行漏转」**（区别于已消灭的 G1-G3）：
  单样本口径下本轮发生率 1/19 调用；词级门禁恰是它的探测器（漏行→覆盖率跌→拦截），分层无漏放风险。
