## 5. 敏感性与风险

1. **卡密度**是最大不确定项（13±3 卡/章按 24 章单点折算）：±3 卡/章 → 全量费用 ±$15、出图时长 ±25%。pilot 即可校准。
2. **token 折算**按 1.25~1.5 字符/token；step2a 契约模板体量（strict schema 注入）未实测，若模板 >20K tok 则 2a 输入费用上浮 ~50%（绝对值 <$5，不影响量级）。
3. **vision 复核量**受 vision_max_hints 政策影响；若放开上限且 55 章类高冲突章占比高，最坏按 57 条/章 ×10% vision 率 → 上限 ~370 次（仍 <$5）。
4. **单价**为示例价：真实中转按次计费时以第 3/4 节「调用次数」列直接乘次单价即可。
5. 55 章型冲突密集章（57 条）提示人工确认负载分布不均：pending_human 尖峰章建议排到专门审阅时段。

## 6. 建议决策路径

1. **先 65 章 shadow 实跑**（≈$3 API + 1~5 小时机器 + 人工确认另计）：零风险验证 V2 管线全量吞吐与 V1/V2 对拍面。
2. **冒烟五章真实 pilot（≈$5，1 小时）**：校准卡密度、真实单价、step4 成功率三个不确定项。
3. 拿 pilot 实测回填第 4 节后再拍 **65 章全量真实跑（当前估 ≈$65~72，半天~1 天）**。
